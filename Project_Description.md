# MentorLink — AI-Powered Mentor-Mentee Intelligence System

**MentorLink** is a premium, full-stack SaaS dashboard designed for intelligent mentorship management. It empowers organizations and individuals by streamlining the mentorship process, providing actionable insights, and fostering meaningful connections between mentors and mentees. 

The application is built with modern web technologies, focusing on a premium user experience with responsive design, dynamic animations, and intuitive data visualizations.

## Core Objective
To replace traditional, manual mentorship tracking with an intelligent, data-driven platform that highlights relationship health, automates engagement tracking, and provides smart recommendations for both mentors and mentees.

## Key Features

- **Role-Based Portals**: Tailored experiences for three distinct roles:
  - **Admin**: Complete overview of the system, including risk detection and analytics.
  - **Mentor**: Management of assigned mentees, session tracking, and workload indicators.
  - **Mentee**: Personal progress tracking, activity heatmap, and achievement unlocking.
- **Relationship Intelligence Score**: A dynamic score (0-100) reflecting the strength and engagement level of a mentorship pairing.
- **Risk Detection System**: Proactive identification of "At Risk" mentees versus those who are "Healthy" in their progress.
- **Activity Heatmap**: A visual 12-week grid (similar to GitHub contributions) tracking engagement and session frequency.
- **Smart Recommendations**: AI-driven, rule-based suggestions to guide mentors and mentees on their next best actions.
- **Mentor Load Indicator**: Visual cues showing if a mentor has a Light, Optimal, or Overloaded schedule.

## Technology Stack

The project utilizes a modern and robust technology stack:

- **Frontend**: React 18, Vite, Tailwind CSS v4, Framer Motion (for animations), Recharts (for data visualization), Lucide React (for icons), and React Router v6.
- **Backend**: Node.js and Express.
- **Data & Auth**: Currently uses an in-memory mock JSON architecture with plans/components built for robust Firebase, Firestore, JWT, and bcrypt integration (based on recent upgrades).

## Design Philosophy
MentorLink employs a premium "glassmorphism" aesthetic with a dark theme (deep blues, teals, and purples). It prioritizes smooth micro-animations and a clean, symmetric 12-column grid layout to deliver a professional SaaS feel.
